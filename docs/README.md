当前 Desktop 通过本机 `/api/desktop/*` 调用正式用例，插件通过冻结 LMCP 接口连接；不开放旧的 plan/task/proficiency 实验模型、基础词条 CRUD 或用户标签管理。当前个人编辑边界及正式词本命令见 [词库与规划查询](词库与规划查询.md)。

冻结 LMCP 规范和 Schema 保存在 `src/main/resources/lmcp`，内部完整学习领域快照保存在 `src/main/resources/domain`。它们是构建输入，不能用排版工具改写或在运行时下载替换；业务说明以本目录为入口。
