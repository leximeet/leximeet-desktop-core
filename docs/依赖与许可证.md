# 依赖与许可证

项目采用仓库 [GNU AGPL v3](../LICENSE)，使用 SPDX 标识 `AGPL-3.0-only`。分发可执行 Jar 时同时提供对应源码、构建说明、许可证和第三方声明；桌面整体分发还需遵守词典、JRE 与宿主物料的各自条件。

## 直接运行时依赖

| 依赖 | 固定版本 | 上游许可信息 |
| --- | --- | --- |
| Spring Boot / Spring Context | 3.5.16 / 实际传递版本见 SBOM | Apache-2.0 |
| Xerial sqlite-jdbc | 3.50.3.0 | Apache-2.0 / BSD-2-Clause；随包原生 SQLite 声明保留 |
| Jackson databind / jsr310 | 2.21.4 | Apache-2.0 |
| SLF4J nop / api | 2.0.17 | MIT |
| java-fsrs | 1.0.0 | MIT；[完整声明](../THIRD_PARTY_LICENSES/java-fsrs-MIT.txt) |

传递依赖以本轮 `target/bom.json` 和 `bom.xml` 为准，不将表格当成永远不变的完整清单。JUnit 5.13.4 只用于测试，不进入生产 Jar 或运行时 SBOM。Spotless、google-java-format、CycloneDX 和 Maven 插件只在构建期间运行。

Spring Boot repackage 保留每个原依赖 Jar 的 `META-INF`、SPI、spring.factories 与许可，避免将资源扁平合并覆盖。产物还携带项目 LICENSE、java-fsrs MIT 声明与本说明；java-fsrs 上游 Jar 缺少许可文本，因此额外保留其原 MIT 全文。桌面只用普通 `java -jar`，关闭打包插件额外注入的分层提取工具。`scripts/verify-release.py` 逐个检查嵌套依赖许可、冻结资源原字节和源码 Jar，并核对 SBOM 与实际 Jar 名称集合是否相同。

## 固定资源

- `src/main/resources/lmcp` 来自 LexiMeet Connector Protocol 的冻结规范；仅用于本地读取、采集和连接，不带 LMSP 云服务实现。
- `src/main/resources/domain` 保留完整学习领域快照及来源 LICENSE，供本机实体校验和 historyHash；不代表已启用跨设备同步。
- Dictionary 0.0.3 由 Desktop 单独安装/挂载，Core Jar 不打包整库。词条、释义、例句、词书和音频各自保留来源与许可，不能因应用 AGPL 抹去原数据许可。

## 生成与核验

`mvn clean verify` 自动生成 CycloneDX 1.6 JSON/XML，覆盖 compile/runtime 依赖并包含上游许可证元数据；排除 test/provided/system。SBOM 不包括单独安装的词典/JRE/Desktop，完整应用应另生成其物料清单。

正式分发前逐项检查依赖版本、许可文本、对应源码、未知许可与漏洞。SBOM 是可核对清单，不是法律结论或“无漏洞”认证。

配置依据：[Spotless Maven 官方说明](https://github.com/diffplug/spotless/tree/main/plugin-maven)、[google-java-format](https://github.com/google/google-java-format)、[CycloneDX Maven 插件](https://github.com/CycloneDX/cyclonedx-maven-plugin)、[Spring Boot 3.5 打包参数](https://docs.spring.io/spring-boot/3.5/maven-plugin/packaging.html)。

项目 POM 与 SBOM 使用精确的 SPDX `AGPL-3.0-only`；发行校验同时核对该标识与 Jar 内的原许可证，拒绝过时或模糊的 `AGPL-3.0`。文档图表规范见[图表规范](图表规范.md)。
