# LexiMeet Desktop Core 1.1.0

本版为 [词遇 IDEA](https://github.com/leximeet/leximeet-idea) 提供本机只读连接支持。插件需要与包含该 Core 的 Desktop 1.1.0 配套，单独运行 Core 不会提供发现或配对的桌面界面。

- 仅接受 Desktop Main 绑定的固定 IDEA 来源，协商连接管理与词库读取能力。配对确认后授予 `library:read`。
- IDEA 会话可以读取词库与词卡，不能采集、写入、注册宿主能力或复用浏览器的会话。断开或撤销后重新确认才可恢复访问。
- LMCP 1.0.0 冻结物料、schema 100 和现有浏览器、AI 助手连接规则保持不变。

标签任务在 Linux、macOS 和 Windows 上执行 JDK 21 测试和真实 Jar 启动。通过后才公开 Linux 检查使用的 Jar、源码 Jar、完整源码、许可证与 CycloneDX SBOM。下载后在同一目录运行 `shasum -a 256 -c SHA256SUMS` 核对，Windows 可使用 `Get-FileHash` 对照。
