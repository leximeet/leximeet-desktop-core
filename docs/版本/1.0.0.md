# LexiMeet Desktop Core 1.0.0

词遇桌面端的本机资料与学习核心，使用 JDK 21、SQLite 和 FSRS-6。它通过 Desktop 或本机 API 工作，不是独立的桌面界面。

## 交付内容

- Dictionary 0.0.3 只读查询、目标逻辑引用、遇见语境、笔记、多单词本、回收恢复与当前格式备份。
- 六种冻结练习、各模式独立断点、0–30 分规则 v2、可重放学习事件及 FSRS-6 排程。
- LMCP 本机发现、确认连接、授权读卡、原子采集、稳定回执与撤权。
- 默认单句限长、脱敏和忽略大小写的七天同词同语境查重。
- 大型词典范围的批量冻结、正式 note-only 个人内容和安全启动错误分类；旧实验路由与未发布数据兼容层已退休。

## 下载与验证

[GitHub Release](https://github.com/leximeet/leximeet-desktop-core/releases/tag/1.0.0) 提供可执行 `leximeet-core.jar`、Java 源码 Jar、`bom.json` / `bom.xml`、完整 `leximeet-desktop-core-1.0.0-source.tar.gz`、`LICENSE`、`SOURCE.json`、`release-verification.json` 和 `SHA256SUMS`。

下载到同一目录后执行 `shasum -a 256 -c SHA256SUMS`。需要 Java 21；[快速开始](https://github.com/leximeet/leximeet-desktop-core/blob/1.0.0/docs/快速开始.md)说明启动参数、回环鉴权和隔离资料。源码 Jar 不包含全部构建入口；完整源码归档包含 Maven 配置、测试、脚本和文档。

标签流水线等待 Linux、macOS、Windows 三平台的全部检查及真实 `java -jar` 验证通过，再复用 Linux 检查产物，附标签对应的完整源码和摘要。Core 的三平台结果不能代表 Desktop 安装、系统通知或其他客户端已经通过验收。POSIX 权限位专项按文件系统能力运行，其余隔离时钟与路径规则保持。

## 版本边界

首次正式资料结构为 schema 100；不迁移未发布测试库，拒绝不支持的文件时保留原资料。本版本没有账号或云同步；Desktop 固定 `core-java` gitlink，LMCP 来源由随包冻结记录核对。
