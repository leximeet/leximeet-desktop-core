# LexiMeet Desktop Core 1.0.1

在 1.0.0 本机词典、练习和 LMCP 连接之上，增加「AI 助手连接」：把本机词典、单词本和学习进度提供给 Cursor、Codex、Claude Code。走私有 `/api/mcp`，与插件用的冻结 LMCP 1.0.0 分开。它通过 Desktop 或本机 API 工作，不是独立的桌面界面。

## 交付内容

- 路由式工具 `leximeet_help` / `leximeet_describe` / `leximeet_query` / `leximeet_write`。参数校验、结果上限和协议协商在 Core。
- 默认只读。设置键 `assistantWriteEnabled` 默认 false；唯一写入 `add_to_vocab` 复用 collect/capture，可用 `mutationId` 幂等。`record_review` 一律拒绝。
- JSON-RPC 通知静默忽略；协议优先协商 `2025-06-18`，旧版本不回新字段；未知工具回 `-32602`；限流只计 `tools/call`。
- `mutationId` 按 MCP `clientId` 隔离并保存请求指纹；同键不同请求回 `INVALID_ARGUMENT`。`list_encounters` 非法日期回 `INVALID_ARGUMENT`。
- 未引入官方 MCP Java SDK：该 SDK 2.x 依赖 Jackson 3，与本仓 Jackson 2.21.4 冲突；协议形状按官方 JSON-RPC / tools 对齐。

1.0.0 的词典查询、冻结练习、LMCP、schema 100 与默认采集政策保持不变。

## 下载与验证

[GitHub Release](https://github.com/leximeet/leximeet-desktop-core/releases/tag/1.0.1) 提供可执行 `leximeet-core.jar`、Java 源码 Jar、`bom.json` / `bom.xml`、完整 `leximeet-desktop-core-1.0.1-source.tar.gz`、`LICENSE`、`SOURCE.json`、`release-verification.json` 和 `SHA256SUMS`。

下载到同一目录后执行 `shasum -a 256 -c SHA256SUMS`。需要 Java 21；[快速开始](https://github.com/leximeet/leximeet-desktop-core/blob/1.0.1/docs/快速开始.md)说明启动参数、回环鉴权和隔离资料。源码 Jar 不包含全部构建入口；完整源码归档包含 Maven 配置、测试、脚本和文档。

标签流水线等待 Linux、macOS、Windows 三平台的全部检查及真实 `java -jar` 验证通过，再复用 Linux 检查产物，附标签对应的完整源码和摘要。配套 Desktop 已公开 [1.0.1](https://github.com/leximeet/leximeet-desktop/releases/tag/1.0.1)，`core-java` gitlink 固定为 [`a98afa8`](https://github.com/leximeet/leximeet-desktop-core/commit/a98afa8bddeab75d98a3751b15a87184be5256dd)。Core 的三平台结果不能代表 Desktop 安装、系统通知或真实助手客户端已经通过验收。POSIX 权限位专项按文件系统能力运行，其余隔离时钟与路径规则保持。

## 版本边界

资料结构仍为 schema 100；不迁移未发布测试库，拒绝不支持的文件时保留原资料。本版本没有账号或云同步。LMCP 来源由随包冻结记录核对。AI 助手默认只读，写入授权可撤销，且不随备份恢复。
