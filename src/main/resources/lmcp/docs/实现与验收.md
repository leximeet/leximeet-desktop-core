# 实现与验收

本仓交付 Schema、方法表、规范、样例和内存参考模型，不提供生产 SDK。contract.json 的 runtimeImplemented=false 表示本仓不包含应用运行时；jointAcceptancePassed=false 表示本次交付身份的应用回归应在消费端记录，不能拿 npm run verify 当作应用验收。

## 各端职责

| 部分 | 必须完成 |
| --- | --- |
| Desktop / Core | 业务鉴权、身份校验、原子采集、持久配对与回执、读取摘要 |
| Browser | 可信后台切换核心适配器、封存 A、统一入口和旧异步响应隔离 |
| Native Host / Main | 真实来源校验、受限 IPC、有界帧、连接失效传播 |
| 可选宿主能力 | 逐项声明真实能力，独立授权和动作回执 |

```mermaid
flowchart LR
  A[Schema 与参考模型] --> B[各端单元和集成]
  B --> C[真实扩展 Host Desktop]
  C --> D[失联 重启 未知结果]
  D --> E[随包 JRE 安装物与人工验收]
```

## 共同验收清单

| 场景 | 必须观察到 |
| --- | --- |
| 两端预置不同资料后连接 | A 封存；B 不导入 A；插件读 B |
| 连接采集 C 再断开 | Desktop 为 B+C；Browser 恢复原 A |
| 旧管理页、浮球、侧栏和后台并发 | 无入口写封存 A；旧响应不跨 owner 代次 |
| 采集失败、ACK 丢失和快速重复操作 | 失败无半事务；同意图重试只一条事实，可查回执 |
| Desktop 退出、Host / Worker 重启 | 不自动降级写 A；不无限启动 Desktop |
| 工作区、generation、授权变化 | 旧会话/缓存失效；未知命令不改投新空间 |
| 双方发现、发起、确认、取消与断开 | 最终在真实插件窗口确认；秘密不进 UI |
| 配对 ACK 丢失和跨进程重启 | 原票据恢复原结果，不重复创建配对 |
| 邀请过期、origin / client 不符 | 明确拒绝，不签发业务会话 |
| 无可选能力与撤销页面权限 | 基础连接仍可用；相关操作受当前授权约束 |
| 管理页与桌面深链接 | 管理转到 Desktop；设置只保留断开；路由白名单 |
| 正式服务新增可选响应或扩展 | 基础接口仍可用，未知业务枚举不伪装成功 |

账号、云 token、在途云响应和 LMSP 的真实同步属于应用 2.0.0，首次 1.0.0 不伪造已登录或云同步功能。

自动化只使用临时数据库、测试扩展 ID、隔离浏览器 profile 和可撤销的 Host 注册。区分结构验证、参考模型、组件模拟、真实跨进程和安装物证据；模拟 Native Port 不能替代真实扩展。测试报告记录版本、平台、命令及故障恢复结果，不放用户数据、秘密或本机绝对路径。
